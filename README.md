# VYNFORGE.ZP

Одностраничный сайт для GitHub Pages.

## Структура
- `index.html` — разметка
- `style.css` — дизайн
- `script.js` — UA/RU и фильтры портфолио

## Перед публикацией
1. В `index.html` замени `https://t.me/` на свой Telegram username/link.
2. Замени `https://instagram.com/` на свой Instagram.
3. При желании замени декоративные плитки портфолио реальными фотографиями.
4. Если есть готовый логотип VF, его можно добавить в `<img>` вместо текстового знака.

## GitHub Pages
Загрузи эти файлы в репозиторий и включи:
Settings → Pages → Deploy from branch → main → / (root).
